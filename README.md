# UTE-Ultimate-Travel-Experience
UTE (Ultimate Travel Experience): Full-stack web &amp; mobile app for planning trips, booking tours, custom itineraries, interactive maps, mock bookings, reviews, wishlists, trip sharing, admin/company dashboards. Tech: ASP.NET Core + EF Core + SQL Server, Flutter, React. Team: 6 (2 Backend, 3 Flutter, 1 React).
